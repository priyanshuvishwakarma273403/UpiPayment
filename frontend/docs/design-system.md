# SentinelX — Enterprise Design System Guide

## Overview
Light-theme first enterprise SaaS aesthetic tailored for high-volume financial fraud intelligence operations.

## Design Tokens & Colors
- **Surfaces:** `#ffffff` (Card/Container), `#f8fafc` (Page canvas), `#0f172a` (Hero/Accent text).
- **Typography:** `Inter` / System Sans-serif with `JetBrains Mono` for IDs, UPI handles, amounts, and hashes.
- **Semantic Risk Indicators:**
  - `CRITICAL` — Crimson / Red (`bg-rose-50 border-rose-200 text-rose-800`)
  - `HIGH` — Amber / Orange (`bg-amber-50 border-amber-200 text-amber-800`)
  - `MEDIUM / LOW` — Blue / Emerald (`bg-blue-50 text-blue-800`, `bg-emerald-50 text-emerald-800`)

## Component Library (20 Primitives)
`Button`, `Input`, `Select`, `Checkbox`, `Badge`, `Tooltip`, `Dropdown`, `Modal`, `Drawer`, `Tabs`, `Card`, `DataTable`, `Pagination`, `Breadcrumb`, `Toast`, `SkeletonLoader`, `EmptyState`, `ErrorState`, `Timeline`, `StatCard`.
